# Design notes

Non-normative notes behind the SPEC: implementation notes, spikes, acceptance walk-throughs and the
reasons a mechanism is built the way it is. The SPEC (`docs/spec/`) states the rules; these files
explain them. A note here never overrides the SPEC. Files are named by topic (`architect.md`,
`board.md`, …); `docs/spec/MAP.md` says which old SPEC section moved to which file.
